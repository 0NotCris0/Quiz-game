# Quiz-game 

## 👥 Integrantes del equipo y reparto de tareas

El proyecto está desarrollado por cuatro integrantes: **Christian, Albert, Adria y Joan**.

Cada integrante tiene asignadas diferentes tareas para organizar el desarrollo y facilitar el trabajo en equipo.

### 👨‍💻 Christian - Organización, preguntas y documentación

Christian es el encargado de organizar el proyecto mediante GitHub Projects, preparar las preguntas del quiz y redactar la documentación.

**Tareas principales:**

- Crear el tablero Kanban en GitHub Projects.
- Configurar las columnas Todo, In progress, Review y Done.
- Invitar a los cuatro integrantes al tablero.
- Crear los issues y asignar las tareas a cada integrante.
- Preparar entre 10 y 15 preguntas para el quiz.
- Crear cuatro opciones para cada pregunta e indicar la respuesta correcta.
- Convertir las preguntas a un array de objetos JavaScript.
- Integrar el array de preguntas en el archivo `script.js`.
- Comprobar que las preguntas se carguen correctamente.
- Redactar las instrucciones del juego.
- Explicar el funcionamiento de la puntuación y el temporizador.
- Crear y mantener el archivo `README.md`.
- Revisar las preguntas y probar varias partidas completas.
- Realizar la revisión final de la documentación y del repositorio.

### 👨‍💻 Albert - Repositorio, estructura HTML y resultados

Albert es el encargado de crear la estructura inicial del proyecto, preparar el HTML y mostrar la pantalla final de resultados.

**Tareas principales:**

- Crear las carpetas y archivos iniciales del proyecto.
- Crear el repositorio en GitHub.
- Dar acceso al repositorio a los demás integrantes.
- Realizar y subir el primer commit.
- Crear el archivo `index.html`.
- Maquetar el título y el contenedor principal del juego.
- Crear la zona de preguntas y los cuatro botones de respuesta.
- Añadir los elementos de puntuación y temporizador.
- Crear el botón Siguiente.
- Preparar el contenedor de la pantalla final de resultados.
- Incluir los elementos para mostrar la puntuación final, los aciertos y los fallos.
- Añadir el botón Reiniciar a la estructura HTML.
- Definir los IDs y las clases que utilizarán CSS y JavaScript.
- Compartir los IDs y clases con Adria y Joan.
- Enlazar los archivos `style.css` y `script.js` con el HTML.
- Comprobar que los archivos se carguen sin errores.
- Implementar la visualización de la pantalla final al terminar las preguntas.
- Mostrar los resultados utilizando los datos de aciertos y fallos que guarda Joan.
- Probar una partida completa y detectar errores en la lógica del juego.

### 👨‍💻 Adria - Diseño CSS y responsive

Adria es el encargado de desarrollar el diseño visual del juego y adaptarlo a diferentes dispositivos.

**Tareas principales:**

- Elegir la paleta de colores del proyecto.
- Definir las tipografías y los tamaños del texto.
- Diseñar el fondo y el contenedor principal.
- Estilizar el título y las preguntas.
- Diseñar los cuatro botones de respuesta.
- Añadir efectos hover a los botones.
- Estilizar el botón Siguiente.
- Crear las clases CSS para respuestas correctas e incorrectas.
- Utilizar el color verde para las respuestas correctas.
- Utilizar el color rojo para las respuestas incorrectas.
- Diseñar la visualización de la puntuación y el temporizador.
- Estilizar la pantalla final de resultados preparada por Albert.
- Diseñar el botón Reiniciar.
- Adaptar la página a móviles, tablets y ordenadores.
- Utilizar Flexbox, Grid y media queries.
- Comprobar el diseño en diferentes tamaños de pantalla.
- Revisar los elementos HTML y sus IDs para detectar posibles errores.

### 👨‍💻 Joan - Lógica JavaScript, puntuación y temporizador

Joan es el encargado de desarrollar el funcionamiento principal del juego mediante JavaScript.

**Tareas principales:**

- Mostrar en pantalla las preguntas preparadas por Christian.
- Mostrar las cuatro opciones de cada pregunta.
- Detectar cuándo el jugador selecciona una respuesta.
- Comprobar si la respuesta seleccionada es correcta o incorrecta.
- Aplicar las clases CSS creadas por Adria para mostrar el resultado.
- Bloquear las opciones después de responder.
- Implementar el funcionamiento del botón Siguiente.
- Controlar el índice de las preguntas para avanzar en orden.
- Calcular los aciertos del jugador.
- Actualizar la puntuación después de cada respuesta.
- Guardar los aciertos y fallos en variables que Albert pueda utilizar.
- Implementar un temporizador con cuenta atrás para cada pregunta.
- Reiniciar el temporizador al cambiar de pregunta.
- Pasar automáticamente a la siguiente pregunta cuando se agote el tiempo.
- Implementar el funcionamiento del botón Reiniciar.
- Restablecer la puntuación y las preguntas para comenzar otra partida.
- Revisar el funcionamiento de los estilos CSS durante el juego.

## 🧪 Pruebas y revisión del proyecto

Cada integrante también es responsable de probar una parte del trabajo de sus compañeros.

| Integrante | Pruebas asignadas |
|------------|-------------------|
| Christian | Revisar las preguntas y jugar varias partidas completas. |
| Albert | Probar la lógica del juego y detectar posibles errores. |
| Adria | Revisar la estructura HTML y comprobar los IDs. |
| Joan | Comprobar los estilos CSS durante el funcionamiento del juego. |

Además, todos los integrantes deben:

- Corregir los errores encontrados en su propia parte.
- Añadir comentarios claros y descriptivos al código.
- Comprobar que sus funcionalidades funcionan correctamente.
- Preparar una explicación del código desarrollado y de cómo se ha generado.

Christian será el encargado de realizar la revisión final del README, los comentarios y el repositorio.
